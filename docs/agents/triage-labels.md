# 分流标签

工程技能使用五个标准分流角色，下表映射到本仓库问题跟踪器中的实际标签。

| 标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求明确，可交给自主智能体实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个角色时，使用对应的仓库标签。需要适配现有命名时，修改“仓库标签”列。
