# 领域文档

本仓库采用 single-context（单上下文）布局。

## 探索代码前读取

- 根目录 `GLOSSARY.md`：领域术语及其定义。
- `docs/adr/`：读取与当前工作范围相关的架构决策记录。

若文件或目录尚不存在，直接继续，不提示缺失，也不预先建议创建。`/domain-modeling`（可经 `/grill-with-docs` 和 `/improve-codebase-architecture` 触发）会在术语或决策明确后按需创建。

## 文件布局

- `GLOSSARY.md`：整个仓库共用的术语表。
- `docs/adr/`：整个仓库共用的架构决策记录目录。

## 使用术语表中的词汇

在问题标题、重构建议、假设或测试名称中提及领域概念时，使用 `GLOSSARY.md` 定义的名称，避免使用其明确排除的同义词。

若需要的概念尚未收录，先判断是否引入了项目未使用的概念；确有缺口时，记录供 `/domain-modeling` 处理。

## 显式指出 ADR 冲突

建议与已有 ADR 冲突时，明确指出相关 ADR 及重新讨论的理由，不静默覆盖既有决策。
